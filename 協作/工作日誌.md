## 2026-09-23｜建立第一版 MVP 網站

### 使用者授權

- 使用者要求直接開始架「莓好預約站」。
- 專案已獨立推上 `jikong0709/meihau-booking`，因此開始在該 Repository 建立第一版前端。

### 技術選擇

- 第一階段使用原生 HTML / CSS / JavaScript。
- 不引入框架、套件管理器或建置工具。
- 理由：目前主要目標是先驗證服務分類、價目呈現、估價與預約 Workflow；靜態站可直接本機預覽，也方便之後上 GitHub Pages 或其他靜態平台。

### 已完成

- 建立 `index.html`：品牌首頁、共享辦公、創作空間、跑腿配送、完整試營運價目、預約表單、營運規則。
- 建立 `styles.css`：桌機與手機響應式版型。
- 建立 `app.js`：方案選擇、固定價估算、機車／汽車距離估價、急件倍率、等待費、停靠費、代買服務費與需求單摘要。
- 預約需求單目前只在瀏覽器產生，不會傳到伺服器，不會自動付款或成立正式訂單。
- 同步更新 README、Session Context 與目錄地圖。

### 價格標記

- 頁面明確標示為「MVP 試營運價目」。
