# 莓好預約站

獨立的預約服務專案，承接光言工作室的共享辦公、創作空間與台中預約跑腿／配送需求。

## 目前狀態

第一版 **MVP 靜態網站** 已建立：

- 共享辦公服務與試營運價目
- 錄音／Podcast、攝影／直播、化妝／更衣服務
- 機車／汽車配送、代買與跑腿試算
- 手機版響應式介面
- 前端即時估價
- 預約需求單產生與複製

目前**尚未**串接：資料庫、正式訂單、付款／訂金、Google Calendar、自動通知、會員與後台。

> 目前頁面上的價格為 MVP 試營運測試價，不等同正式上線價格。

## 專案檔案

```text
index.html      # 網站結構與內容
styles.css      # 響應式視覺樣式
app.js          # 方案資料、估價與需求單互動
README.md       # 專案入口
_SESSION_CONTEXT.md
專案目錄地圖.md
協作/
```

## 本機預覽

不需要安裝套件，可直接開啟 `index.html`。若需要用本機 HTTP Server：

```bash
python -m http.server 8080
```

再開啟 `http://localhost:8080`。

## 專案原則

- 與其他 Repository、分支及產品完全獨立。
- MVP 先驗證服務、價目、資訊架構與預約流程。
- 正式付款、客戶資料寫入與部署操作必須另外確認。
- 不在 Repository 紀錄 token、API key、密碼或其他私密憑證。
